# CardioMEMS Markov Model

## Overview

This repository contains an R implementation of a cohort-based Markov model developed for a cost-effectiveness analysis comparing CardioMEMS with usual care.

## Project Status

**Work in Progress**

This repository represents an active research project. The code will continue to evolve throughout the peer review and publication process.

## Model Features

- Cohort-based Markov model
- Monthly cycle simulation
- Cost estimation
- QALY estimation
- Discounting
- Deterministic sensitivity analysis
- Probabilistic sensitivity analysis
- Scenario analyses
- Price-threshold analysis

## Repository Files

- Deterministic base-case analysis
- Probabilistic sensitivity analysis (PSA)
- Scenario analysis 1
- Scenario analysis 2

## Disclaimer

This repository is intended to demonstrate the methodological implementation of the model in R. It does not necessarily represent the final version of the model, as the code may continue to be refined throughout the peer review and publication process.
